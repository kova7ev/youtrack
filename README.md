# YouTrack #

Веб приложение для учета времени, затраченного на проекты участниками.

### Импользуемые технологии ###

* Java
* Tomcat
* Spring
* Spring MVC
* Hibernate
* H2 DB

### Требования ###
##### Основные #####

* Аутентификация пользователя (login)
* Просмотр данных, введенных пользователем, по всем проектам, назначенным на
пользователя, на указанную дату
* Добавление записи о произведенных действиях по проекту на указанную дату. Запись
содержит затраченное время и комментарий. Возможно наличие более чем одной записи
для проекта на указанную дату
* Правка данных, введенных пользователем в рамках записей на указанную дату
* Самостоятельное назначение (выбор) проектов, в которых участвует пользователь и по
которым он намерен проставлять время
* Смена пароля

##### Дополнительные ####
* Добавление нового проекта (название, дата старта)
* Добавление нового пользователя (логин, пароль)
* Просмотр списка пользователей
* Просмотр списка проектов
* Правка свойств проекта (название, дата старта)
* Правка свойств пользователя (имя входа (логин), пароль, является ли администратором)

### Сборка и запуск проекта ###

* Для сборки проекта используется maven, также в репозитории содержит файлы конфигрурации для работы в eclipse
* Для деплоя и теста приложения пожалуйста используйте комманду ```mvn clean install tomcat7:run```
